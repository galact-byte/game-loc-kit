# game-loc-kit

**让 AI 帮你把 PC 游戏做成独立的简体中文副本。**

从提取文本、审核哪些内容可以翻译，到翻译、构建和画面检查，game-loc-kit 为 AI 提供一套可调用的工具。中文版输出到单独目录，不在原版游戏上直接修改。

你提供游戏和可用的 AI 助手，AI 操作工具；你可以通过进度窗口查看状态、暂停或继续翻译，最后试玩生成的中文版。

[下载 Windows 版](https://github.com/galact-byte/game-loc-kit/releases/latest) · [使用指南](docs/USAGE.md) · [开发与发布](docs/DEVELOPING.md)

## 它适合你吗？

如果你有一款想汉化的游戏，也在使用能读写本机文件、执行命令的 AI 编程助手，可以让它借助本工具完成汉化流程。

开始前需要了解：

- **不是双击即用的一键汉化器。** 窗口用于查看进度和控制任务，识别游戏、审核文本、构建与检查由 AI 调用命令行完成。
- **不附带模型或账号。** 翻译使用大模型，需要你已有的 Agent 登录或 API 配置，可能产生模型服务费用；不调用传统机器翻译接口。
- **支持某个引擎，不等于兼容它的所有游戏。** 加密、定制脚本和特殊界面可能需要额外处理；通过文本检查后，仍需进入游戏检查漏翻、乱码和排版。

## 支持哪些游戏？

| 引擎 | 汉化方式 | 额外要求或限制 |
|---|---|---|
| RPG Maker MV / MZ | 替换副本中的数据文本 | 插件和脚本中的文字需要审核 |
| TyranoScript | 替换副本中的剧本文本 | 支持散装剧本及 `app.asar` / `package.nw` |
| 吉里吉里（KiriKiri / KAG） | 生成补丁包 | 部分日文游戏需要转区启动 |
| Wolf RPG Editor | 替换副本中的数据文本 | 加密包需要 UberWolfCli；Wolf 3.x 标题保留原文以兼容存档 |
| Unity | 在画面显示时替换文本 | 需要 BepInEx + XUnity.AutoTranslator |
| Godot 4 | 在画面显示时替换文本 | 游戏内部保留原文 |

不确定游戏使用什么引擎时，可以先让 AI 识别，不必自己判断。外部工具的配置见[使用指南](docs/USAGE.md#环境与外部工具)。

## 开始使用

### 1. 下载并解压

在 [Releases](https://github.com/galact-byte/game-loc-kit/releases/latest) 下载文件名以 `-windows-x64.zip` 结尾的独立包，完整解压到可写目录。Windows 10/11 x64 无需另装 Python 或 PyQt6。

- `glk-gui.exe`：供你打开的任务进度窗口。
- `glk.exe`：供 AI 或命令行调用的工具入口。

请保留整个解压目录，不能只复制一个 EXE。日常使用不需要下载项目源码包或依赖源码包。

### 2. 让 AI 建立汉化任务

将仓库链接、工具解压位置和游戏目录交给能操作本机文件的 AI 助手。可以直接这样说，替换其中的路径即可：

```text
请使用 game-loc-kit 帮我把这款游戏汉化成简体中文。
仓库：https://github.com/galact-byte/game-loc-kit
工具目录：E:/Tools/game-loc-kit
游戏目录：D:/Games/我的游戏
工作区：E:/loc/我的游戏

请先阅读仓库 skills/game-localization/SKILL.md 和 docs/USAGE.md，
确认引擎与所需环境，再按规约执行审核、翻译、构建和画面检查。
不要修改原版，不要在回复中展示剧情、原文或译文。
```

工作区是保存任务配置、原文和译文的文件夹，请放在游戏目录和工具目录之外，不要公开上传。翻译子 Agent 支持 `pi`、`claude`、`codex`、`opencode`，默认使用 `pi`；让 AI 选择你已经安装并登录的那个即可。也可通过大模型 API 领取和提交翻译批次，详见使用指南。

**权限提醒：** 子 Agent 会读写文件和执行命令；部分预设跳过交互确认，其中 Codex 预设关闭审批与沙箱。只在你信任的环境中运行。

### 3. 查看进度，试玩中文版

AI 建好工作区后，双击 `glk-gui.exe`，选择包含 `glk.json` 的工作区文件夹。

窗口可以查看阶段、翻译数量和错误记录，也可以暂停、继续或取消翻译。暂停会等当前批次完成；取消会保留已提交译文，之后可继续。**关闭窗口不会停止任务。**

翻译进度到 100% 只表示已审核放行的文本翻译完成，不代表整个汉化流程结束。请等 AI 完成构建和画面检查，再试玩输出目录中的中文版。

## 原版与存档保护

- 创建工作区时记录原版文件指纹，构建前后核对；中文版写入独立目录。
- 在引擎允许时隔离中文版存档；工具执行截图测试时，会备份并还原可能共用的存档位置。重要存档仍建议自行备份。
- 先审核文字用途，保护代码标识、资源路径和逻辑判断用的字符串；无法确定用途时不翻译。
- 未翻译、格式标记丢失、术语冲突或校验记录过期时，阻止正常构建。检查不能代替实际游玩验证。

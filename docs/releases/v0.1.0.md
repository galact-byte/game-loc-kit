这是 game-loc-kit 的首个 GitHub Release。主要流程仍由 AI 通过命令行完成，这次加上了供用户查看进度和控制翻译的 PyQt6 窗口。

### 任务进度窗口

- 显示正在执行的步骤、已耗时、翻译工作进程状态；详细错误可以展开查看。
- 翻译进度条显示已完成／总数、百分比和剩余条数。待审核文本单独列出，不混入进度分母。
- 支持暂停、继续和取消翻译。暂停会等当前批次完成；取消会停止翻译进程及其子进程，保留已经提交的译文，之后可以继续。
- 多个窗口查看同一个工作区时，不会重复启动翻译。关闭窗口后，任务继续运行。
- 可以打开日志目录；生成输出后，可以直接打开输出目录。

窗口里的 100% 只表示已放行文本翻译完成。用途审核、质量检查、构建和游戏内检查仍需分别完成；无法测量进度的步骤只显示“处理中”。

### 下载和启动

需要 Windows 10/11、Python 3.10 或以上。发布包不内置 Python、PyQt6 或翻译模型，也不包含游戏文件。

**安装 wheel**：下载 `game_loc_kit-0.1.0-py3-none-any.whl`，在下载目录运行：

```bat
python -m pip install "game_loc_kit-0.1.0-py3-none-any.whl[all,gui]"
glk-gui
```

只用命令行时，可以不安装 `gui` 依赖。已有工作区也可以直接运行 `glk --ws "工作区路径" gui`。

**使用源码包**：下载并解压 `game_loc_kit-0.1.0.tar.gz`，在解压后的目录运行 `python -m pip install ".[all,gui]"`，再双击 `start-gui.bat`。启动脚本本身不会自动安装依赖。

打开窗口后，选择包含 `glk.json` 的**工作区目录**。工作区的创建、文本提取与用途审核仍由 AI 调用 CLI 完成，具体命令见 [README](https://github.com/galact-byte/game-loc-kit/tree/v0.1.0#readme)。翻译依赖本机已配置、可正常使用的 Agent；窗口不会代为登录或配置模型。

`SHA256SUMS.txt` 提供 wheel 和源码包的 SHA-256 校验值。

### 验证与限制

Windows 自动构建会运行全部 41 项测试和代码检查，检查包内资源与许可文件，并从仓库外启动已安装 wheel 的 CLI 和 Qt 窗口，通过后才发布。

暂停、恢复、取消及窗口启动翻译的链路使用模拟 Agent 和真实子进程验证。本次没有调用真实模型翻译整款游戏，也没有据此承诺所有游戏均可直接汉化。各引擎需要的外部工具见 README。

旧版 CLI 启动的任务没有阶段记录：窗口能读取文本数量，完整阶段显示和控制需要用本版本 CLI 重新启动任务。AI 在 CLI 之外的思考过程无法显示为进度。

game-loc-kit 首个发布版本，提供从文本提取、用途审核、AI 翻译到质量检查和中文版构建的命令行流程。

 ### 功能

 - 支持 RPG Maker MV/MZ、TyranoScript、吉里吉里、Wolf RPG Editor、Unity 和 Godot 4。
 - 支持通过 pi、Claude Code、Codex 或 OpenCode 执行翻译任务。
 - 构建前检查漏翻、变量与格式标记、术语冲突；中文版输出到独立目录，保留原版游戏文件。

 ### 任务进度窗口

 - 查看当前步骤、翻译进度、剩余数量和错误记录。
 - 支持暂停、继续和取消翻译，保留已提交的译文。
 - 关闭窗口后任务继续运行；多个窗口不会重复启动同一工作区的翻译。
 - 可直接打开日志目录和生成的输出目录。

 ### 当前限制

 - 窗口用于查看和控制任务，工作区创建、文本提取及构建仍由命令行完成。
 - 翻译进度达到 100% 后，仍需完成质量检查、构建和游戏内验证。

### Windows 独立包

- 新增 `game-loc-kit-0.1.0-windows-x64.zip`，完整解压后双击 `glk-gui.exe`，无需安装 Python 或 PyQt6。
- 同目录保留 `glk.exe`，供 AI 和命令行调用；翻译仍需已配置的 Agent。
- wheel 和项目源码包继续提供；依赖源码附件用于查阅和重建，日常使用无需下载。
